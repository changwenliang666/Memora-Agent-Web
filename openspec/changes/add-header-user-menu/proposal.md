## Why

工作台顶栏右侧目前只有「退出」文字按钮，看不到当前账号，也无法从身份入口展开后续账户操作。登录已经写入账号，需要把它变成稳定的身份控件，并让退出收进菜单，桌面和手机共用同一套交互。

## What Changes

- 工作台顶栏右侧增加圆形头像：中心显示当前账号名的后 3 位；账号不足 3 位时显示全部。
- 头像背景使用与平台主色、侧栏藏青同一谱系的靛蓝，浅色 / 深色各自有对应色，文字用白色以保证对比。
- 点击头像展开下拉菜单；本阶段菜单只提供「退出登录」。
- 退出不再以顶栏独立文字按钮出现；主题图标按钮位置与行为不变。
- 手机宽度沿用同一顶栏头像与下拉，不把退出塞进左侧抽屉。
- 登录页不出现该头像菜单。

不包含：账户中心、改密、头像上传、完整账号文案展示、权限角色。

## Capabilities

### New Capabilities

- （无）

### Modified Capabilities

- `app-shell`: 顶栏用账号头像和下拉菜单提供身份识别与退出，桌面与手机同一入口。
- `auth`: 会话必须提供可展示的账号，供顶栏生成后 3 位标识。

## Impact

- 布局：`src/layouts/AppLayout.vue` 顶栏右侧替换「退出」按钮为头像菜单。
- 状态：读取现有 `auth` 会话中的 `account`，退出仍走 `clearSession` 并进入登录页。
- 样式：新增头像色令牌，下拉菜单沿用现有表面色、边框和文字色。
- 依赖：使用已有 Element Plus 下拉，不新增 UI 库。
