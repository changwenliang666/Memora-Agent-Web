## Why

当前工程按桌面宽度排版，没有统一的断点和适配约定。手机、平板打开时容易出现边距不适、横向溢出或后续页面各写一套样式。需要在业务变复杂之前，先落地一套简单、可控、默认同页扩展的适配方式。

## What Changes

- 让现有首页能在手机、平板上完整查看：内容可读、控件可点、不出现横向滚动。
- 建立统一断点（手机 / 平板 / 桌面）和页面适配约定，PC 默认样式与窄屏覆盖互不污染。
- 默认一套 Vue 页面 + 断点样式完成适配；仅当 DOM 结构差异很大时，才拆布局壳并复用同一套业务逻辑，避免功能写两遍。
- 为后续页面提供可复用的断点工具（样式 mixin + 必要时的 JS 断点判断）。

不包含：独立移动端站点或路由、引入 Vant 等第二套 UI 库、rem/vw 全局缩放、按 User-Agent 分流、为首页复制一份移动端页面。

## Capabilities

### New Capabilities

- `responsive-layout`: 手机、平板、桌面下的可浏览布局，以及后续页面按断点扩展而不与 PC 样式冲突的约定。

### Modified Capabilities

- 无。主规格目录尚无已归档能力；主题色能力与本变更正交，需求不改。

## Impact

- 样式：全局断点变量 / mixin、基础溢出与安全区处理；`HomeView` 增加窄屏覆盖。
- 代码：新增轻量断点查询（仅结构分叉时使用）；不改路由与主题存储。
- 依赖：不新增 npm 包；继续使用 Element Plus，不引入移动端组件库。
- 视口：沿用并补强现有 `viewport`（含安全区），不改主题切换行为。
