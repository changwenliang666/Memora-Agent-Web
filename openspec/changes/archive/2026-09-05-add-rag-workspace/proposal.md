## Why

工程仍是骨架首页，无法作为 RAG 平台使用。需要先落下可导航的工作台：知识库问答 / 录入 / 入库记录，以及覆盖问答与向量入库的用量统计，后续才能在同一壳子里接 Cloudflare 上传和真实接口。

## What Changes

- 用左右布局替换骨架首页：左侧系统导航（可展开折叠），右侧功能页；手机改为顶栏 + 抽屉，不另做移动站。
- 知识库作为一级级联菜单，子路由为问答、录入、入库记录；默认进入问答。
- 用量作为第二个一级菜单，按小时 / 天 / 周 / 月 / 年查看问答与入库的 token 消耗，用折线、柱状、饼图展示。
- 问答页以对话为主：进页滚到历史底部；Enter 发送、Shift+Enter 换行；流式走 `fetch + ReadableStream`，并避免长会话整表重绘。
- 录入页提供上传区，上传实现留空位供后续接 Cloudflare；入库记录页展示文件入库状态。
- 主题开关从骨架首页移到壳顶栏；骨架首页不再作为落地页。

不包含：多会话历史、Cloudflare 真传、设置页、费用/按模型分析、前端把问答或录入实时写入用量、虚拟列表库、第二套 UI 库。

## Capabilities

### New Capabilities

- `app-shell`: 应用壳、级联导航、默认路由、侧栏折叠与手机抽屉、顶栏主题开关。
- `knowledge-chat`: 知识库问答对话、键盘发送、进页贴底、SSE 流式读取与长列表性能约束。
- `knowledge-ingest`: 知识库文件录入（上传函数留空）与入库记录列表。
- `usage-stats`: 按时间粒度查看问答 vs 入库的 token 用量，并用三类图展示。

### Modified Capabilities

- 无。主规格目录尚无已归档能力。主题开关位置变化随 `app-shell` 描述，不改未归档的 `theme-mode` 主规格。

## Impact

- 路由与页面：`App.vue` / `router` / `HomeView`；新增壳布局与四个业务页。
- 状态：新增问答、录入/记录、用量的 Pinia 模块；侧栏折叠状态；主题 store 复用。
- HTTP：CRUD 仍走现有 Axios；流式单独模块，不塞进 Axios 实例。
- 依赖：新增 `echarts`，仅按需引入折线、柱状、饼图。
- 样式：沿用现有主题 token 与 768/1200 断点；补表面色等少量 token，不换组件库。
