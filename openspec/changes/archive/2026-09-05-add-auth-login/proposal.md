## Why

工作台目前任何路径都能直接进入，没有登录门槛。需要先挡住未登录和 token 失效的访问，并提供与现有工作台气质一致的登录 / 注册页，后续再替换真实鉴权接口。

## What Changes

- 新增独立登录页，同一页内切换登录与注册；注册本阶段只收集账号和密码。
- 未携带有效 token（不存在或已过期）访问工作台路径时，自动跳转到登录页。
- 登录成功后进入原先要去的页面，默认落到知识问答。
- 已登录用户打开登录页时，回到工作台，不停留在登录表单。
- 登录与注册走占位接口：接口形状先定好，本阶段不接真实后端，页面可完整走通。
- 有效会话写入 localStorage；请求带上 token；401 或过期时清会话并回到登录页。
- 工作台顶栏提供退出，便于结束会话并回到登录页。

不包含：短信 / 邮箱验证、第三方登录、找回密码、权限角色、真实鉴权后端、记住密码以外的账户中心。

## Capabilities

### New Capabilities

- `auth`: 登录 / 注册页、会话持久化、路由守卫、占位鉴权接口与退出。

### Modified Capabilities

- `app-shell`: 应用壳只包已登录的工作台路由；顶栏增加退出入口。登录页不使用侧栏壳。
- `http-client`: 共享客户端在有会话时附带认证头；收到 401 时清会话。

## Impact

- 路由：`App.vue` 改为根 `router-view`；工作台路由挂到 `AppLayout` 下；新增 `/login`。
- 状态：新增会话 Pinia，读写 localStorage 中的 token 与过期时间。
- HTTP：`src/api/http.ts` 增加请求头与 401 处理；新增 `src/api/auth.ts` 占位登录 / 注册。
- 页面：新增登录视图；壳顶栏增加退出。
- 依赖：不新增 UI 库或鉴权库。
